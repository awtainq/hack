# V90: самостоятельный подбор моделей по прошлым сезонам

V90 обучается на исходных регистрациях и календаре ЕГЭ. Бакалавриат,
магистратура и остальные программы имеют отдельные модели. Прогнозы V84,
оценки лидерборда и итоги кампании 2024 года не участвуют в обучении,
калибровке и выборе параметров.

Подбор улучшил исторические результаты относительно отдельных моделей V89
без учителя. Однако приблизиться к прогнозу V84 не удалось: средняя абсолютная
разница — **29.99 регистрации в день**, сумма выше на **13.90%**.
Public RMSLE V90 неизвестен. Подтверждения результата ниже 0.4 нет.

## Как выбирались параметры

Данные: `processed_data/registered.csv` и `external_data/ege/exam_calendar.csv`.
Прогнозируется число строк регистраций за 20 июня — 31 августа, а не число
уникальных людей. Бакалавриат и специалитет объединены в один поток,
магистратура — во второй, СПО и другие программы — в третий.

Для каждого потока проверено 80 конфигураций: 48 CatBoost, 16 Random Forest,
16 Extra Trees. Каждая проверяется на 2017, 2018, 2019, 2021, 2022 и 2023
годах. Всего в итоговом поиске — 1 440 обучений. Для прогноза каждого сезона
используются только предыдущие сезоны; 2020 год исключён как аномальный.

Перебирались:

- CatBoost: глубина 3/5, 300/700 итераций;
- леса: 192 дерева, минимум 3/8 наблюдений в листе;
- период полураспада весов исторических сезонов: 2/6 лет;
- признаки: календарь; календарь с уровнями двух предыдущих сезонов;
  дополнительно расстояния до дат ЕГЭ;
- выравнивание исторических сроков по найденным в истории изменениям активности.

Все модели учатся на `log1p` количества своего потока. Общий прогноз — сумма
трёх потоков. Нулевые субботы определяются по частоте нулей в предыдущих
сезонах; воскресенья обнуляются календарным правилом.

Критерий выбора — взвешенный по давности средний полный 73-дневный RMSLE.
Сначала выбираются параметры по каждому потоку, затем проверяются замены
параметров одного потока при фиксированных остальных для улучшения общей
суммы. Алгоритм выполняет максимум четыре таких прохода.

Также проверен один общий коэффициент. Для каждого проверяемого сезона он
оценивается только по ошибкам более ранних исторических прогнозов. На пяти
сопоставимых сезонах средний критерий составил 0.580076 без коэффициента и
0.580125 с ним. Поэтому автоматический выбор оставил коэффициент **1.0**.
Нормировки к 11 400, 9 131 или 2 301 нет.

Все шесть сезонов использованы при выборе параметров. Это разработческая
валидация, а не независимый тест после подбора. Итоговый прогноз 2024 года
строится по сезонам 2014–2023 за исключением 2020.

## Выбранные модели

| Поток | Модель | Деревья | Глубина / минимум в листе | Полураспад весов | Признаки | Выравнивание истории |
|---|---|---:|---|---:|---|---|
| Бакалавриат и специалитет | CatBoost | 700 | глубина 3 | 2 года | календарь, прошлые уровни, ЕГЭ | нет |
| Магистратура | CatBoost | 700 | глубина 5 | 6 лет | календарь, прошлые уровни, ЕГЭ | да |
| СПО и другие программы | Extra Trees | 192 | минимум 8 в листе | 6 лет | календарь, прошлые уровни, ЕГЭ | нет |

Для CatBoost скорость обучения — 0.035, L2 — 10. Для Extra Trees доля
признаков — 1.0. Полные параметры и протокол сохранены в
`output/v90/selected_config.json` и `output/v90/validation_protocol.json`.

## Исторические результаты

| Год | V90, полный RMSLE |
|---|---:|
| 2017 | 0.42480 |
| 2018 | 0.41771 |
| 2019 | 0.49225 |
| 2021 | 0.68881 |
| 2022 | 0.48094 |
| 2023 | 0.67626 |

Взвешенный критерий по шести сезонам — **0.56861**. Для ранее обученной
самостоятельной V88 на тех же сезонах — 0.56897: преимущество очень небольшое.
На 2022 и 2023 годах V88 лучше V90: 0.46802 и 0.67049 соответственно.

Относительно V89 только с историческим обучением результаты улучшены:
2021 — 0.70678 → 0.68881; 2022 — 0.52820 → 0.48094;
2023 — 0.71229 → 0.67626. Улучшение не означает достижения Public < 0.4.

## Сравнение с V84 после фиксации модели

До чтения значений V84 для этого сравнения сохранены SHA-256 исходников,
параметров, весов и готового прогноза в `output/v90/selection_frozen.json`.
Отдельный `compare_v90.py` проверяет эти хеши, читает прогнозы и записывает
только диагностику. После сравнения параметры и прогноз не изменялись.

| Показатель | V84 | V90 |
|---|---:|---:|
| Сумма регистраций | 11 400.00 | 12 985.02 |
| Отклонение суммы от V84 | — | +13.90% |
| Средняя абсолютная разница с V84, в день | — | 29.99 |
| Средняя абсолютная относительная разница по ненулевым дням V84 | — | 34.61% |
| Максимальная абсолютная разница | — | 220.23 |
| Нулевые даты | 13 | те же 13 |

Это сходство двух прогнозов, не ошибка относительно фактических данных.
Итоги V90 по потокам: бакалавриат — **9 944.44**, магистратура — **2 054.34**,
СПО и другие программы — **986.24**.

Близость V89 к V84 обеспечивалась обучением на V84. В V90 это условие убрано,
поэтому прежняя близость не сохранилась. Выдавать V90 за воспроизведение
результата V84 0.39140 оснований нет.

## Запуск

```bash
.venv/bin/python -m pip install -r requirements-v90.txt
.venv/bin/python v90_model.py predict
```

Повторное обучение по уже выбранным параметрам с сохранением отдельной копии:

```bash
.venv/bin/python v90_model.py train \
  --model /tmp/v90_retrain/model.joblib \
  --output /tmp/v90_retrain/forecast.csv
```

Полный подбор по истории выполняет `evaluate_v90.py`; он перезаписывает
результаты эксперимента V90. Диагностика исходной зафиксированной версии:

```bash
.venv/bin/python compare_v90.py
.venv/bin/python -m unittest discover -s tests -p 'test_v90*.py' -v
```

Пять тестов прошли. Проверены отдельные целевые переменные, отсутствие
влияния фактических строк будущего года, временная граница калибровки,
восстановление общего коэффициента на данных с известным множителем,
сохранение лесов и обучение CLI в каталоге без старых прогнозов.
Полное повторное обучение и прогноз из сохранённых весов дают CSV,
побайтно совпадающий с готовым файлом.

## Основные файлы

- `v90_model.py` — модель, обучение и прогноз; подготовка данных использует
  общие функции `v88_model.py`, без загрузки весов или прогнозов V88.
- `evaluate_v90.py` — автоматический подбор только по прошлым сезонам.
- `forecast_2024_v90.csv` — готовый общий прогноз.
- `output/v90/degree_forecasts.csv` — три потока и сумма.
- `output/v90/backtest_metrics.csv` — ошибки по сезонам.
- `output/v90/comparison_with_v84.csv` — сравнение по каждой дате.
- `output/v90/comparison.png` — график сравнения и потоков.
- `output/v90/metadata.json` — происхождение данных, параметры и хеши.

Существующие прогнозы V84, V89 и основной `forecast_2024.csv` не перезаписаны.
