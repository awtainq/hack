# V93: фиксированные настройки, выбранные по прогнозу V84

Рабочая модель в `v93_model.py` обучает отдельные регрессоры бакалавриата,
магистратуры и остальных программ только на исторических регистрациях.
При повторном обучении и прогнозировании файл V84 не требуется.

Пользователь проверил `forecast_2024_v93.csv` на лидерборде и сообщил
**Public RMSLE 0.39621**. Это оценка общего прогноза, а не отдельных потоков.

**Гиперпараметры выбраны по близости к V84. Поэтому полный процесс разработки
зависит от V84 и не является независимым историческим подбором.** Удаление
названия учителя из рабочего модуля не меняет происхождения параметров.
Происхождение сохранено здесь и в `output/v93/metadata.json`.

## Разделение поиска и рабочего кода

Рабочие файлы:

- `admissions_calendar.py` — исходные регистрации и календарные признаки;
- `v93_model.py` — обучение, сохранение весов и прогноз;
- `output/v93/selected_config.json` — фиксированная конфигурация трёх потоков.

`v93_model.py` не читает старые прогнозы, результаты лидерборда, исходный
файл V84 или параметры из его кода. Конфигурация содержит обычные параметры
регрессоров: глубину и число деревьев, скорость обучения, регуляризацию,
веса сезонов, длину истории, метод прогноза годового уровня и набор признаков.
Массивов поправок по датам и заранее заданных будущих дневных количеств нет.
Общий множитель к сумме не применяется.

Отдельный `tune_v93.py` явно читает V84 и ранжирует конфигурации по сходству
прогнозов. Каждый регрессор-кандидат обучается на исторических строках.
Значения V84 не передаются регрессору как обучающие цели; они используются
для оценки гиперпараметров и выбора комбинации трёх потоков. Это всё равно
зависимость от учителя, а не независимая проверка точности.

## Поиск параметров

Первый этап: 1 484 комбинации потока и конфигурации — исходная сетка и
случайный воспроизводимый поиск. Затем выполнены два уточнения по 540
конфигураций около найденных настроек. Всего проверено **2 564 кандидата**.
Поиск не усредняет старые CSV и не переносит коэффициенты модели V84.

Первые этапы минимизировали среднюю абсолютную разницу с V84. Такой выбор
сильнее учитывает большие июльские дни. Для итогового ранжирования сохранённого
пула использована взвешенная абсолютная разница:

```text
mean(abs(прогноз - V84) / sqrt(1 + V84))
```

Она повышает значимость небольших дней, сохраняя вклад июльских пиков.
Дополнительно отбираются только кандидаты, чей календарь закрытых дней
согласуется с V84. В рабочий код конкретный список дат не переносится:
нулевые воскресенья задаёт календарное правило, субботы определяются
по исторической частоте нулей с выбранными весами сезонов.

Комбинация трёх потоков выбирается с восьми начальных состояний, затем
проверяются совместные изменения двух потоков. Для кандидатов, выбранных
на последнем этапе, заново обучены модели по истории и сохранены веса.

## Итоговая конфигурация

| Поток | Модель | Основные параметры |
|---|---|---|
| Бакалавриат и специалитет | CatBoost, RMSE по логарифму | 500 деревьев, глубина 4, скорость 0.04503, L2 2.94888, полураспад 2.42195 года |
| Магистратура | CatBoost, MAE по логарифму | 300 деревьев, глубина 7, скорость 0.14172, L2 2.18439, полураспад 3.04043 года |
| СПО и остальные программы | сплайновая регрессия | 5 узлов, штраф 0.03204, полураспад 2.92180 года |

Бакалавриат использует календарные координаты, даты ЕГЭ и тренд уровня
последних трёх сезонов. Магистратура использует признаки относительно своего
срока, выравнивание исторических сроков, последние пять нормальных сезонов
для обучения профиля и последние три для тренда уровня. Для остальных
программ выбран профиль по положительным историческим дням без отдельного
годового уровня. Все точные числа записаны в конфигурации; числа в таблице
округлены только для чтения.

Исходные данные — `registered.csv` за 2014–2023 годы и календарь ЕГЭ.
Аномальный 2020 год исключён. Считаются строки регистраций, а не уникальные
люди или зачисленные. Годовой уровень — средний `log1p` дневных регистраций
по будням, а не заранее известная будущая годовая сумма.

## Сходство с прогнозом V84

| Показатель | V91 | V93 |
|---|---:|---:|
| Средняя абсолютная разница с V84, регистраций/день | 22.69 | **10.36** |
| Средняя абсолютная относительная разница по положительным дням V84 | 28.31% | **12.05%** |
| Сумма регистраций | 12 162.86 | **11 035.40** |
| Совпадение нулевых дат с V84 | да | да |

Сумма V84 — 11 400.00. Сумма V93 ниже на 364.60 регистрации (3.20%).
По потокам V93: бакалавриат — **8 197.35**, магистратура — **2 131.20**,
остальные программы — **706.85**. В V84 нет отдельных потоков для проверки
этого разложения.

Средняя абсолютная разница уменьшилась примерно на **54.4%** относительно
V91. Почти точного совпадения одним подбором гиперпараметров не получено.
Эти показатели рассчитаны по той же V84, по которой выбирались настройки:
они описывают обучающее сходство, а не независимую точность. **Отдельно
измеренный пользователем Public score V93 — 0.39621; у V84 — 0.39140.**

## Ретроспективная проверка фиксированных настроек

| Год | V91 | V93 |
|---|---:|---:|
| 2022, полный RMSLE | 0.51479 | 0.56088 |
| 2023, полный RMSLE | 0.64846 | 0.71816 |

На этих годах V93 хуже V91. Это ещё одна причина отличать имитацию прогноза
V84 от подтверждённого улучшения самостоятельного прогнозирования.
Проверка выполнена после подбора настроек по V84; она не является новым
слепым тестом.

## Запуск

```bash
.venv/bin/python -m pip install -r requirements-v93.txt
.venv/bin/python v93_model.py predict
```

Отдельные потоки выбираются параметром `--degree`:

```bash
.venv/bin/python v93_model.py predict --degree bachelor
.venv/bin/python v93_model.py predict --degree master
.venv/bin/python v93_model.py predict --degree all
```

Первая команда создаёт `forecast_2024_v93_bachelor.csv`, вторая —
`forecast_2024_v93_master.csv`. Оба файла содержат столбцы `date,forecast`.
Вариант `all` сохраняет все потоки и сумму в
`forecast_2024_v93_components.csv`. Также доступны `--degree background`
для СПО и остальных программ и `--degree total` для общего прогноза.
По умолчанию выбирается `total`. Путь можно задать через `--output`.
Параметр работает и с командой `train`: он выбирает экспортируемый поток,
а обучение по-прежнему сохраняет все три модели.

Экспорт отдельных потоков не меняет веса или общий прогноз. Бакалавриат
и магистратура вместе не включают третий поток СПО и остальных программ.

Повторное обучение только по исходной истории и фиксированной конфигурации:

```bash
.venv/bin/python v93_model.py train \
  --model /tmp/v93_retrain/model.joblib \
  --output /tmp/v93_retrain/forecast.csv
```

Для этого запуска V84 и результаты лидерборда не нужны. После сохранения
весов `predict` также не читает историю, ЕГЭ и конфигурацию.

Скрипт поиска отделён от рабочего модуля:

```bash
.venv/bin/python tune_v93.py
.venv/bin/python tune_v93.py --refine
.venv/bin/python tune_v93.py --select-only --objective balanced
```

Поиск перезаписывает артефакты V93 и требует V84. Зафиксированная конфигурация
и обученные веса воспроизводят поставленный прогноз; повторный новый поиск
может выбрать другие настройки. Сохранены все проверенные конфигурации
и их прогнозы для аудита.

## Проверки и файлы

Четыре теста прошли:

- изменение учителя меняет выбор конфигурации, поэтому проверка не независима;
- добавление фактических будущих строк не меняет обучение при фиксированной конфигурации;
- календарь закрытых дней обеспечивается выбором кандидатов, без списка дат в рабочем коде;
- CLI обучается в каталоге без старых прогнозов и воспроизводит результат из сохранённых весов.

В CLI-проверке также проверены отдельные экспорты каждого потока и таблица
всех потоков: значения совпадают с компонентами сохранённой модели, а общий
CSV остаётся побайтно прежним.

Полное повторное обучение по выбранной конфигурации и прогноз из сохранённых
весов дают CSV, побайтно совпадающий с поставленным файлом.

```bash
.venv/bin/python -m unittest discover -s tests -p 'test_v93*.py' -v
.venv/bin/python plot_v93.py
```

Готовый прогноз — `forecast_2024_v93.csv`. Компоненты —
`output/v93/degree_forecasts.csv`. Ежедневное сравнение —
`output/v93/reference_comparison.csv`. Происхождение параметров и хеши —
`output/v93/metadata.json`. Исходные V84 и основной прогноз не перезаписаны.
