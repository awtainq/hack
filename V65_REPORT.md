# V65: самостоятельная модель, Public RMSLE 0.53550

**V65 — один обученный CatBoost.** Он читает только исходные
`registered.csv` и `included_ks.csv`. Итоговый прогноз получается непосредственно
из первого выхода этой модели. Старые прогнозы V59–V64, их коэффициенты и
оценки лидерборда в расчёте V65 не используются.

Готовый CSV: `forecast_2024_v65_standalone.csv`.
Код: `v65_standalone.py`.
Обученные веса: `output/v65/model.cbm`.
**Пользователь сообщил Public score за 2024 год: 0.53550. Модель хуже V61 (0.42430).**

## Устройство модели

Основная цель — `log1p` общего количества зарегистрированных заявлений за день.
Вспомогательные цели — бюджет, договор, бакалавриат, магистратура, СПО и остальные
уровни образования. Все семь целей обучаются внутри одного CatBoost с общими
деревьями и раздельными выходными координатами.

Это позволяет выбирать разбиения деревьев с учётом разных фаз приёма. В файле
для лидерборда используется только непосредственно предсказанное общее число.
Бюджетные, договорные и остальные прогнозы в итог не складываются.

Для вспомогательной бюджетной цели записи КС соединяются по абитуриенту,
дню и типу заявления. При наличии бюджета/Гослинии регистрация относится
к бюджету, остальные — к договору. Общее количество регистраций сохраняется.
Неоднозначность выбора человеком источника финансирования не меняет основную
целевую величину общего потока.

Признаки:

- День недели, этап кампании и календарный год.
- Расстояние до дедлайнов бакалавриата и магистратуры, включая рабочие дни.
- Дни недели самих дедлайнов, начало кампании, период дипломов и приказов.
- Фактический поток прошлых лет на сопоставимую дату и день недели.
- Поток относительно прошлогодних дедлайнов, сглаженные недельные уровни.
- Объёмы прошлогодней кампании и прошлогодняя доля подачи через Госуслуги.

Все исторические признаки для прогнозируемого сезона используют только более
ранние годы. Факт за прогнозируемый год не нужен. Дополнительный тест полностью
удаляет проверяемый год из обоих CSV: признаки и расписание закрытых дней
остаются неизменными.

Выбраны **700 деревьев глубины 3**, скорость обучения 0.035 и L2-регуляризация 10.
Веса давности имеют период полураспада 4 года. Сдвинутый пандемийный сезон 2020
учитывается с пониженным весом. Основная цель масштабирована в два раза,
чтобы её квадрат ошибки имел больший вес, чем каждый вспомогательный выход.

Рабочий календарь задаётся отдельным правилом из прошлых сезонов: воскресенья
и субботние периоды с преобладанием нулевых дней закрыты. Это не второй
обученный алгоритм и не использование готового прогноза другой модели.
Для 2024 года правило даёт 13 закрытых дат.

## Подбор и проверка

Проверены **26 конфигураций** на пяти временных разделениях: 2017, 2018, 2019,
2021, 2022. Для каждого разделения использованы только более ранние сезоны:
**130 обучений**. Проверены обычная и многомерная цели, глубина, число деревьев,
веса давности, вклад основной цели и календарные варианты без лагов.

Функция выбора — половина среднего RMSLE по пяти сезонам и половина среднего
по двум последним, 2021–2022. Это даёт больший вес более современному режиму
подачи документов. Результаты 2023 года в функцию выбора не входят.

| Проверяемый сезон | RMSLE V65 |
|---|---:|
| 2017 | 0.46068 |
| 2018 | 0.50373 |
| 2019 | 0.47490 |
| 2021 | 0.65645 |
| 2022 | 0.56246 |
| Среднее по пяти сезонам выбора | **0.53164** |
| Дополнительный контроль 2023 | **0.68453** |

На 2023 году V59 по ранее выполненной проверке имела RMSLE 0.74346. В V65 он
снизился до 0.68453; по будним дням — с 0.51710 до **0.38521**. Совпадение
расписания закрытых дней V59 и V65 для этого сравнения отдельно проверено.
Обе модели прогнозируют тот же полный сезон и те же регистрации.

После выбора параметров выполнены дополнительные проверки 2023 года:

| Вариант | RMSLE | RMSLE по будням |
|---|---:|---:|
| Выбранная V65 | 0.68453 | 0.38521 |
| Одна цель с теми же параметрами | 0.69982 | 0.42287 |
| Выбранные параметры без лагов | 0.67744 | 0.36935 |

Совместное обучение целей помогло этому сравнению. Лаги не дали равномерного
выигрыша: на дополнительном 2023 году их удаление немного улучшило результат.
V65 сохраняет конфигурацию, выбранную по пяти предыдущим сезонам; контрольный
год не используется для очередной перенастройки. Эти результаты сохранены
полностью, включая неудачные варианты.

Исторические оценки нельзя напрямую сравнивать с Public score 0.42430 за другой,
2024 год. Они подтверждают работоспособность подхода, но не гарантируют результат
ниже 0.42430. Фактическая проверка дала 0.53550; улучшение исторической метрики не перенеслось на 2024 год.

## Прогноз 2024 и использование

- 73 последовательные даты: 20 июня — 31 августа.
- Суммарный прогноз **12 784.12** регистраций.
- 13 нулевых дней по рабочему календарю.
- Все значения конечные, неотрицательные, округлены до двух знаков.
- Максимальный дневной прогноз — 672.60.

Из корня проекта:

```bash
# Восстановить прогноз из готовых обученных весов
.venv/bin/python v65_standalone.py --predict

# Заново обучить одну выбранную модель по данным 2014–2023
.venv/bin/python v65_standalone.py --train

# Полностью повторить подбор по прошлым сезонам и обучение
.venv/bin/python v65_standalone.py --search --train

# Проверки самостоятельной модели
.venv/bin/python -m unittest discover -s tests -p 'test_v65_standalone.py' -v
```

Файл `requirements-v65.txt` фиксирует версии зависимостей. При изменении исходных
данных, кода признаков или сохранённых весов режим `--predict` требует заново
обучить модель. Контрольные суммы сохраняются в метаданных.

Пять тестов прошли: источники ограничены двумя исходными CSV; будущие метки
не влияют на признаки и расписание; вспомогательные цели сохраняют число
регистраций; прогноз берётся прямо из первого выхода одной модели и сохраняется
после записи/чтения `.cbm`; пропущенные промежуточные сезоны диагностируются.
Режим восстановления из весов воспроизвёл CSV побайтно.

- `output/v65/model.cbm` — одна обученная модель.
- `output/v65/selected_config.json` — выбранные параметры.

- `output/v65/check_2023.json` — результат дополнительного контроля.

- `output/v65/ablations_2023.json` — дополнительные сравнения, не использованные
  для выбора параметров.
