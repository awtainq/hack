# V89: отдельное обучение бакалавриата и магистратуры

V89 обучает три самостоятельных CatBoost: бакалавриат, магистратура и остаток
(СПО и другие программы). Затем отдельный обучаемый слой приближает сумму
прогнозов к V84. Это прямо соответствует задаче сравнивать с результатами V84.
**Итоговая V89 зависит от V84. Её Public RMSLE пока неизвестен.**

## Как устроено обучение

1. Из `registered.csv` строятся ежедневные количества регистраций по уровням
   образования за 20 июня — 31 августа. Каждая строка регистрации учитывается
   один раз. Цель — регистрации, а не уникальные люди или зачисленные.
2. Для прогноза 2024 используются только сезоны 2014–2023. Аномальный сезон
   2020 исключён. Более свежие сезоны получают больший вес с периодом
   полураспада три года.
3. Каждая из трёх моделей обучается на собственном `log1p` количества
   регистраций. Признаки: календарь, положение относительно сроков приёма,
   контекст двух предшествующих сезонов и расстояния до дат ЕГЭ. Признаки
   готовятся общими функциями из `v88_model.py`; веса и прогнозы V88 не читаются.
4. Закрытые субботы определяются по взвешенной частоте нулей в истории.
   Воскресенья обнуляются календарным правилом. Конкретные даты 2024 не
   прописаны списком.
5. Обучается регуляризованная регрессия поправки к `log1p` общей суммы.
   Её целевая переменная — разница между V84 и суммой трёх моделей.
   Признаки поправки — сплайны времени, день недели, этап приёма и
   взаимодействия дня недели со сплайнами. Штраф на коэффициенты — 0.1.
6. Поправка применяется к сумме, после чего распределяется пропорционально
   исходным прогнозам потоков. Поэтому исторически обученные доли бакалавриата,
   магистратуры и остальных программ сохраняются для каждого дня.

Годовые суммы 9 131 / 2 301 и нормировка к 11 400 не задаются. Прогноз V84
читается явно на этапе калибровки, его хеш записан в артефакте модели.
Индивидуальных поправок для конкретных дат нет.

## Сравнение именно с прогнозом V84

Эти показатели измеряют сходство двух прогнозов, **не ошибку относительно
фактических регистраций**. Все 73 даты участвуют в сравнении; относительные
отклонения считаются только по 60 датам, где V84 положительна.

| Показатель | Только историческое обучение | V89 после калибровки | V84 |
|---|---:|---:|---:|
| Сумма за период | 12 355.08 | 11 384.26 | 11 400.00 |
| Средняя абсолютная разница с V84, регистраций/день | 22.63 | 7.18 | — |
| Средняя абсолютная относительная разница с V84 | 27.93% | 6.26% | — |
| Максимальная абсолютная разница с V84 | 126.67 | 69.37 | — |
| Нулевые даты | те же 13 | те же 13 | 13 |

Наибольшее расхождение после калибровки — 10 июля: V84 даёт 625.00,
V89 — 555.63. Общее отклонение суммы — минус 15.74 регистрации, или 0.14%.
Сходство на этих же датах является результатом обучения по V84, а не
независимой проверкой переноса на новые сезоны.

| Поток | До калибровки | После калибровки |
|---|---:|---:|
| Бакалавриат и специалитет | 9 403.45 | 8 521.94 |
| Магистратура | 2 055.77 | 2 076.81 |
| СПО и другие программы | 895.86 | 785.50 |

V84 предоставляет только общий прогноз. Поэтому разложение 2024 года по
уровням образования нельзя проверить по V84: это оценка исторических моделей.
У V84 подтверждён пользователем Public 0.39140. Эта оценка не переносится
на V89; близость прогнозов сама по себе не гарантирует результат ниже 0.4.
Зависимость V84 от обратной связи лидерборда также сохраняется через учителя.

## Воспроизведение

Из корня проекта, Python 3.10:

```bash
.venv/bin/python -m pip install -r requirements-v89.txt
.venv/bin/python v89_degree_model.py train
.venv/bin/python v89_degree_model.py predict
.venv/bin/python compare_v89.py
```

Первая команда обучения создаёт три базовых CatBoost и калибровку по V84.
Файл `output/v89/config.json` содержит все параметры конфигурации; их можно
передать через `--config`. Настройки не оптимизировались по Public score V89.
При `predict` исходные регистрации и CSV учителя не читаются: достаточно
сохранённого `output/v89/model.joblib` и модулей проекта.

Для самостоятельного исторического варианта без учителя:

```bash
.venv/bin/python v89_degree_model.py train --historical-only
.venv/bin/python v89_degree_model.py predict --historical-only
```

Он сохраняется отдельно в `output/v89/historical_model.joblib` и
`forecast_2024_v89_historical.csv`. Его близость к V84 существенно ниже.

## Файлы и проверки

- `v89_degree_model.py` — обучение, калибровка, сохранение и прогноз.
- `forecast_2024_v89.csv` — общий прогноз для загрузки.
- `output/v89/degree_forecasts.csv` — прогноз по трём потокам и их сумма.
- `output/v89/reference_comparison.csv` — построчное сравнение с V84.
- `output/v89/comparison.png` — график сумм и потоков.
- `output/v89/metadata.json` — происхождение данных, параметры и SHA-256.
- `output/v89/*_base.cbm` — отдельные модели CatBoost до калибровки.

Пять проверок в `tests/test_v89_degree_model.py` подтверждают отдельные цели
трёх моделей, отсутствие влияния фактических строк будущего года, сохранение
долей после калибровки, проверку входного прогноза учителя и загрузку весов без
исходных CSV. Полное повторное обучение и прогноз из сохранённых весов дают
побайтно одинаковый CSV. SHA-256 исходного `forecast_2024_v84.csv` проверен:
он не изменился. Скрипты V89 записывают отдельные файлы и не перезаписывают
основной `forecast_2024.csv`.

```bash
.venv/bin/python -m unittest discover -s tests -p 'test_v89*.py' -v
```
