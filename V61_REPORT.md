## Расчёт

Все операции выполняются в пространстве `log1p(число регистраций)`.
Обозначения: `u` — V59, `v` — V60, `p` — прежний общий прогноз без разбиения
на потоки (`forecast_2024_clean_deadline_blend.csv`). Его воспроизведение
проверено по обученным компонентам: совпадение до сотой на всех датах.

```text
d = u - p                         # старое направление общей/потоковой модели
h = v - u                         # изменение разбиения финансирования
k = mean(h*d) / mean(d*d)
r = h - k*d                       # часть изменения, ортогональная d
```

В V59 коэффициент старого направления уже подбирался по лидерборду. Чтобы
не сдвигать его повторно, V61 использует только остаток `r`. Корреляция `h`
со старым направлением составляет примерно −0.754: существенная часть V60
двигала прогноз обратно по уже исследованному направлению.

Для одного и того же набора оцениваемых дней квадрат RMSLE при изменении прогноза
в пространстве `log1p` является квадратичной функцией. Из двух известных оценок
следует оценка скалярного произведения с остаточной ошибкой:

```text
A = (mean(h*h) + score_V59**2 - score_V60**2) / 2
estimated_optimal_step = A / mean(r*r)
step = 0.75 * estimated_optimal_step
z_V61 = u + step*r
```

Приняты два допущения: геометрия по всем 73 датам приближает неизвестный состав
публичной выборки; V59 близка к локальному минимуму по старому направлению `d`.
Поэтому расчётный результат не является измеренной оценкой и не гарантирует
улучшения на публичной или приватной выборке. Параметры используют Public score
2024 года; независимой проверкой качества будущих сезонов этот расчёт не является.

Расчётный оптимальный шаг — 0.70727; используется 75% этого шага, **0.53045**.
Дополнительно ограничены среднеквадратичное изменение в логарифмах до 0.03
и максимальное изменение отдельного дня до 0.10. Для текущих файлов эти
ограничения не сработали: фактический среднеквадратичный шаг составляет 0.02079.

Итог эквивалентен линейной комбинации логарифмических прогнозов:

```text
z_V61 = 0.6092981842 * z_V59
      + 0.5304546495 * z_V60
      - 0.1397528337 * z_pooled
```

Отрицательный коэффициент общего прогноза сохраняет характер экстраполяции V59.
Готовые значения проверяются на конечность и неотрицательность.

Семь тестов для V60/V61 проверяют сохранение количества регистраций,
независимость от порядка строк и будущих меток, соответствие календаря,
привязку оценок к точным файлам и математический расчёт на синтетическом примере
с известными фактическими значениями. Отдельно проверено совпадение V61 с
эквивалентной линейной комбинацией до сотой на каждой дате.
