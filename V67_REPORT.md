# V67: V61 с мягкими ориентирами объёма кампании

Готовый файл: **`forecast_2024_v67_volume_prior.csv`**.
База — проверенная V61 с Public RMSLE **0.42430**.
**Public score V67 неизвестен.** Лучший подтверждённый файл остаётся V61.

## Происхождение ориентиров

Пользователь сообщил приблизительные итоги кампании: 9 131 для бакалавриата
и специалитета, 2 301 для магистратуры с МИЭП. Пользователь также уточнил,
что точное определение итогов ему неизвестно. Не подтверждено, означают ли
они зарегистрированные заявления, уникальных абитуриентов или зачисленных,
и полностью ли совпадает период с 20 июня — 31 августа.

Поэтому это **внешние неточные ориентиры**, а не фактические метки 2024 года
и не независимо найденные моделью числа. Они находятся отдельно от кода
в `volume_priors_2024.json`, с происхождением `user_provided` и явным
допущением о соответствии периоду прогноза. Вариант условен относительно
этого допущения; при другой трактовке итогов калибровку нужно пересмотреть.

## Модель

1. Основной ежедневный прогноз берётся из V61; другие сабмиты в него не смешиваются.
2. Один CatBoostClassifier обучается на исходных регистрациях прошлых лет
   и оценивает доли трёх групп по датам: бакалавриат, магистратура с МИЭП,
   остальные программы. У каждой группы своя сезонность и разные сроки приёма.
3. Прогноз V61 распределяется по этим долям. Затем общий объём двух групп
   мягко приближается к указанным ориентирам. Внутри каждой группы дневные
   пропорции сохраняются; остальные программы не корректируются.

Калибровка выполняется в логарифмах сезонных объёмов:

```text
w = min(0.75, sigma_model² / (sigma_model² + log(1 + 0.15)²))
adjusted_volume = exp((1 − w) * log(base_volume) + w * log(user_prior))
```

`sigma_model` — ретроспективная RMS-ошибка логарифма объёма группы на шести
прошлых сезонах с большим весом последних лет. 15% — принятое допущение
о неточности ориентира, а не оценка его достоверности. Максимальный вес 0.75
не позволяет заменить прогноз точным внешним числом.

Исторические компоненты V61 используют её фиксированные коэффициенты,
полученные с обратной связью лидерборда 2024. Поэтому расчёт неопределённости
ретроспективный; это не независимая проверка качества V67. Без фактических
данных 2024 года нельзя вычислить её RMSLE локально.

Формат CSV: `date,forecast`, 73 последовательных дня, все значения конечны
и неотрицательны. Все 13 нулевых дат V61 сохранены.

## Воспроизведение и аудит

```bash
.venv/bin/python v67_volume_prior.py
.venv/bin/python -m unittest discover -s tests -p 'test_v67_volume_prior.py' -v
```

Зависимости те же, что в `requirements-v66.txt`. Используется модуль
`v66_calendar_model.py` для построения календарных признаков.

- `output/v67/volumes.csv` — объёмы, веса и множители.
- `output/v67/degree_breakdown.csv` — модельные компоненты прогноза по дням.
- `output/v67/historical_volume_errors.csv` — расчёт неопределённости объёмов.
- `output/v67/degree_share_model.cbm` — обученный классификатор состава потока.
- `output/v67/metadata.json` — происхождение ориентиров, допущения, контрольные суммы.

Проверки защищают независимость долей от меток проверяемого года, мягкость
корректировки, сохранение нулевых дней и неизменность группы без ориентира.
Ни наличие этих проверок, ни близость итогов к заданным числам не гарантируют
снижение RMSLE на лидерборде.
