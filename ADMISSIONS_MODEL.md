# Самостоятельная модель регистраций — V68

`admissions_model.py` обучает модель на `processed_data/registered.csv`.
Выбранная конфигурация — **один CatBoostRegressor**, предсказывающий
`log1p` количества регистраций за день. Обратное преобразование — `expm1`.
Это прогноз регистрационных записей, а не количества зачисленных студентов.

## Устройство

- `ModelConfig`: параметры обучения, доступные в JSON.
- `read_daily_counts`: подсчёт регистраций и заполнение отсутствующих дней нулями.
- `calendar_features`: календарные признаки, доступные до начала кампании.
- `AdmissionsModel.fit / predict / save / load`: обучение и работа с сохранёнными весами.
- `evaluate_admissions.py`: отдельный запуск временной проверки и выбора параметров.

Признаки: день кампании, день недели, месяц, положение субботы в сезоне,
расстояния до сроков приёма, начало кампании и индикатор сезона 2020 года.
Старые сезоны получают вес `2 ** (-возраст / half_life)`; период полураспада
выбран на исторической проверке. Воскресенья и дни без регистраций входят
в обучение. Фиксированного списка закрытых дат нет.

Код не импортирует V59–V67, не читает их CSV или оценки лидерборда. Числа
9 131 и 2 301 не используются: пока неизвестно, сопоставимы ли они с целью.
Зависимости модели — только NumPy, pandas и CatBoost; версии указаны в
`requirements-admissions.txt`.

В коде оставлены два варианта для воспроизведения сравнения: классификатор
активности плюс регрессор положительного потока. В мягком варианте прогноз
в логарифмической шкале умножается на вероятность активности, в жёстком
классификатор определяет нули по порогу 0.5. Они не вошли в итоговую модель.

## Проверка

В каждом временном разбиении обучение получает только сезоны до проверяемого
года. Все 73 дня участвуют в RMSLE; перед расчётом прогноз округляется до двух
знаков, как в итоговом CSV.

| Год | RMSLE V68 | Назначение |
|---|---:|---|
| 2017 | 0.57609 | Выбор параметров |
| 2018 | 0.53748 | Выбор параметров |
| 2019 | 0.46519 | Выбор параметров |
| 2021 | 0.68406 | Выбор параметров |
| 2022 | **0.55926** | Выбор параметров |
| 2023 | **0.68198** | Дополнительная диагностика |
| 2024 | неизвестен | Нет фактических значений и Public score |

Проверены 48 конфигураций: три архитектуры, глубина 3/5, 400/800 деревьев,
период полураспада 2/5 лет, включение/исключение 2020 года. Критерий выбора —
минимальный средний RMSLE по пяти годам 2017–2022 из таблицы. Итог: прямой
CatBoost, глубина 3, 400 деревьев, learning rate 0.04, L2 10, half-life 5;
2020 год включён. Средний RMSLE выбора — около 0.56442.

До этого выполнена проба 16 конфигураций с числовым признаком года. Она
сохранена в `output/v68/exploration_with_year`; признак убран после анализа
ошибок прошлых сезонов. Год 2023 уже неоднократно изучался в этой работе и
предыдущих экспериментах, поэтому его нельзя считать новым слепым тестом.
Показатели выбора параметров также не являются независимой оценкой качества.

Для сопоставления с ранее запрошенной таблицей:

| Модель | RMSLE 2022 | RMSLE 2023 |
|---|---:|---:|
| V61 | 0.58168 | 0.74025 |
| V65 | 0.56246 | 0.68453 |
| V68 | 0.55926 | 0.68198 |

V61 здесь — ретроспективный перенос фиксированных коэффициентов, полученных
с использованием оценок 2024 года; это не независимая историческая проверка.
Её цифры и результаты V65 взяты из `output/v61/backtest_v61_vs_v65.csv`
только для отчёта, они не использовались кодом обучения или выбора V68.
Улучшение исторических показателей не подтверждает улучшение Public score.
Лучший подтверждённый Public score остаётся у V61: **0.42430**.

## Календарные допущения

Период прогноза — 20 июня – 31 августа. Номинальные сроки: бакалавриат
25 июля, магистратура 29 июля с переносом на предыдущий будний день.
Исключение для бакалавриата 2021 года — 29 июля, по
[сообщению Минобрнауки](https://minobrnauki.gov.ru/press-center/news/novosti-ministerstva/32843/).
Остальные сроки в коде — допущения, а не полный проверенный архив правил.
Концы кампаний не определяются по значениям проверяемого года.

## Запуск из корня проекта

Обучить итоговую модель и записать прогноз:

```bash
.venv/bin/python admissions_model.py train --year 2024
```

Получить тот же прогноз из сохранённых весов; исходный CSV не требуется:

```bash
.venv/bin/python admissions_model.py predict
```

Повторить подбор параметров, временную проверку и финальное обучение:

```bash
.venv/bin/python evaluate_admissions.py
```

Проверки границ данных и сохранения модели:

```bash
.venv/bin/python -m unittest discover -s tests -p test_admissions_model.py -v
```

Итоговый файл: `forecast_2024_v68_model.csv`, 73 даты, сумма **10 833.08**.
Сумма получена из ежедневных прогнозов без масштабирования к заданному объёму.
Веса находятся в `output/v68/model/count_model.cbm`; параметры, метрики,
ежедневные ошибки и контрольные суммы — в `output/v68/`.
